# Essai vocal féminin : premier lot

Dix prises générées dans une nouvelle audition choisie par l'utilisateur : fins
singulière et plurielle, reprise, pauses de 1 à 7 minutes. Il n'a pas été possible
de récupérer l'identifiant de la « féminine 2 » d'un ancien test : la voix de ce
lot est celle choisie dans la nouvelle audition, sans garantie d'identité avec
l'ancienne. Les fichiers n'ont pas été validés à l'écoute.

Les pauses de 8 à 60 minutes restent à préparer, ainsi que toute autre annonce
nécessaire après vérification. Ces prises sont publiées pour écoute seulement ;
le minuteur existant n'est pas modifié. Le service de synthèse permet au maximum
dix fichiers par tour : les lots suivants nécessitent des tours ultérieurs.
