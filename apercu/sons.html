🎧 Les 20 sons du Pomodoro — la nouvelle version

Écoute chaque ambiance. Les sons qui « grésillaient comme une radio » sont refaits : plus de fréquence pure, plus de chuintement dans les aigus, plus de clic à chaque redémarrage.

Ce qui a changé
• Binaural gamma / bêta : c'était deux sons purs (un par oreille) posés en avant — d'où le sifflement de radio. Les porteuses passent maintenant très bas sous une nappe chaude ; le battement (40 Hz et 20 Hz) reste exact.
• Pluie, pluie légère, forte pluie, orage, bruit blanc, bruit rose : les aigus (4 000–9 000 Hz) sont adoucis. Ils faisaient 45 à 60 % de l'énergie : c'est exactement le « chuintement » d'une radio mal réglée. Ils descendent à 3–14 %.
• Toutes les ambiances : le grave est rééquilibré bande par bande pour qu'aucun son ne soit sourd, et le niveau de départ est le même pour les 20.
• Boucles : plus aucun clic toutes les 8 secondes (le raccord est coupé là où le signal est plat).
• Cheminée : avant, un souffle continu avec les craquements noyés dessous (1 dB d'écart entre fort et faible). Maintenant le foyer ronfle discrètement, l'air monte dans le conduit et les craquements de bois ressortent nettement (petits tics, salves, gros claquements), avec les braises qui pétillent.
• Orage : avant, le tonnerre était inaudible (2 % d'énergie dans le grave contre 44 % pour la pluie). Maintenant, trois coups de tonnerre qui roulent — lointain, proche, lointain — avec de vrais silences entre eux, et la pluie continue derrière.
